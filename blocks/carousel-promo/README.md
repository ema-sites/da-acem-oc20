# carousel-promo

Custom **carousel** block. Purpose: promo banner slides (banner art carries its own copy) with an overlaid orange CTA, switched by dot controls and auto-advancing every 4s (paused on hover/focus and for reduced motion).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide: | banner image | CTA link (optional heading/text) | optional dot label (falls back to heading or image alt) |.

Desktop CTA offsets per slide (50px / 750px / 35px from the left, 280px from the top) mirror the source banners and repeat every three slides.

## Supported variations

No variations.
