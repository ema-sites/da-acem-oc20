# product-buy-box

Custom **custom** block. Purpose: marketplace PDP buy box: header, gallery, edition/version/support selects, add-on checkboxes, price lines with total, add to cart and contact vendor.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per part, label | value: header (logo + heading + vendor), | Gallery | images |, | Edition | choices |, | [ ] Installation service | $10.00 |, | Product | $0.00 |, | Total | $0.00 |, | action links |, | rating |, other text as info.
