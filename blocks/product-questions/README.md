# product-questions

Custom **custom** block. Purpose: customer Q&A list with answer counts and answer buttons, plus optional header bar.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional header row (| Questions | Ask a question link |), then one row per question: | author · date | question | answer count | answer link |; a links-only row is an actions bar.

## Supported variations

| Variation | Option class |
| --- | --- |
| Ask Button Only | `ask-button-only` |
| Header Bar | `header-bar` |
| Header Bar Error Actions | `header-bar-error-actions` |
