# cards-product

Custom **cards** block. Purpose: grid of uniform extension cards with logo, name, vendor, star rating, partner tier and price.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: | logo image | name (link/heading), vendor, rating ("4.5" or stars), partner tier, price |.
